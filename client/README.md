## 🛠️ Tecnologías Utilizadas
*   **Frontend:** React, Vite, Axios, React Hook Form, Yup
*   **Backend:** Node.js, Express, MySQL (mysql2, bcrypt)
*   **Base de Datos:** MySQL (bdsantos)

## 📝 Descripción
Aplicación web tipo CRUD (Create, Read, Update, Delete) para la gestión de usuarios. Permite crear, listar, editar y eliminar usuarios, con validaciones en el formulario y comunicación en tiempo real con la base de datos.
