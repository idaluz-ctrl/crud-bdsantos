## 📖 Sobre el Proyecto

Este proyecto fue desarrollado como parte de la asignatura **Desarrollo Web**. Consiste en un sistema completo (Frontend + Backend + Base de Datos) para gestionar usuarios, aplicando validaciones estrictas y un diseño visual moderno basado en **Glassmorphism** y una paleta de colores personalizada.

## 🚀 Características Principales

- 🛡️ **Seguridad:** Encriptación de contraseñas con `bcryptjs`.
- ⚡ **Validaciones:** Formularios validados en tiempo real con `Yup`.
- 🎨 **Diseño UI/UX:** Efecto de vidrio esmerilado (Glassmorphism), gradientes suaves y botones interactivos.
- 🔄 **CRUD Completo:** Crear, Leer, Actualizar y Eliminar usuarios sin recargar la página.

## ⚙️ ¿Cómo ejecutarlo localmente?

1. Clona este repositorio.
2. Ejecuta el script `bdsantos.sql` en tu MySQL Workbench.
3. En la carpeta `/server`, crea un archivo `.env` con tus credenciales y ejecuta `npm install` y luego `npm run dev`.
4. En la carpeta `/client`, ejecuta `npm install` y luego `npm run dev`.
